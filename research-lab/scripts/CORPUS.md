# Offline corpus architecture
The official BJT repository is preferred to recrawling every page. Index original source JSON with stable tree positions and preserve original wording, edition, language, passage locator and source URL. Bilara is indexed separately using its canonical segment IDs. Do not silently equate distinct editions.
SQLite FTS5 supports offline lexical retrieval; source hierarchy and reviewed parallel/topic edges supply a conservative graph. This is not yet full LightRAG and does not claim semantic vector ingestion of the entire corpus. BGE-M3 and BGE Reranker must be tested on paraphrases, distractors and source-level recall before full vector build. Do not use generated graph edges as canonical facts.
The build artifact is a test index, not yet wired into live Vercel queries. Keep it separate from the Worker production project. Respect the original source license and attribution, especially BJT CC BY-ND 4.0. No secrets are needed to build from public sources.
